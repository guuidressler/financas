# Finanças

App pessoal (PWA) para lançamentos, fluxo de caixa e investimentos. A tela fica aqui no GitHub Pages; os dados ficam numa planilha Google, acessada por um Apps Script protegido por chave.

Este repositório não contém dados, a URL da planilha nem a chave: elas são informadas no próprio celular, na primeira abertura.
